# Network configuration

This section contains information about setting up the ISP network elements to provide telemetry and logs that are required for the IPDR function.


- [NetFlow](/docs/prodguide/ipdr/netflow): export NetFlow or IPFIX from your gateway routers.
- [AAA and RADIUS](/docs/prodguide/ipdr/radius): add user IDs for dynamic and CGNAT IP addresses.
- [NAT Syslog](/docs/prodguide/ipdr/syslog): send NAT mappings over syslog.
