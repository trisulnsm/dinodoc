# Threshold Bands

:::info Navigation
:point_right: Go to **Alerts &rarr; Threshold Bands**
:::

Threshold Band Anomaly (TBA) Alerts automatically learn the normal behavior of a selected network metric from historical data and create a dynamic threshold band around that normal range. Trisul then monitors the metric in real time and generates an alert when its value moves outside the expected range.

TBA Alerts are useful for detecting unusual increases or decreases in network activity without having to define a fixed threshold manually. The system can account for differences between days of the week and exclude unusual historical spikes when building the baseline.

For detailed information on creating, configuring, viewing, and managing Threshold Band Anomaly Alerts, see [Threshold Band Anomaly Alerts](/docs/guide/ug/alerts/tband).
