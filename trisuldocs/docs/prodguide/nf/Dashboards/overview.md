# Overview

:::info navigation

:point_right: Select *Dashboards &rarr; Overview* to view the Overview Dashboard

:::

The **Overview** dashboard gives you a quick picture of your network and the Trisul system in one place.

At a glance, you can see **overall traffic, current network activity, active flows, alerts, top hosts, top applications, and Trisul system performance**.

Use it when you want to quickly answer:

> **"Is everything behaving normally, and is there anything I should investigate?"**

If something stands out, such as a sudden traffic increase, a busy host or application, an alert, or packet drops, you can use the detailed dashboards to investigate further.


[**Click here → to see current bandwidth, previous day volume comparisons, active flow counts, and alert totals**](https://docs.trisul.org/docs/guide/ug/ui/dashboards#overview-dashboard)
