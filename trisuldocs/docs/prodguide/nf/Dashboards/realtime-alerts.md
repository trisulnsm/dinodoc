# Real Time Alerts

:::info navigation

:point_right: Select *Dashboards &rarr; Real Time Alerts* to view the Real Time Alerts Dashboard

:::

**Real Time Alerts** gives you a live view of IDS security alerts as they happen on the network. Instead of waiting for a dashboard refresh or reviewing alerts after the fact, it lets you see alert activity as it is generated.

This is useful for quickly understanding whether IDS activity is occurring, what types of alerts are being generated, how frequently they are occurring, and which systems or network endpoints are involved.

The view is powered by Trisul's real-time event delivery using WebSockets PUSH, allowing alert events to be sent directly from the Trisul Probe to the browser.


For the live alert view, the bubble chart and pivoting by signature, priority or IP, see [Real Time Alert Stabber](/docs/guide/ug/alerts/ids_stabber) in the User Guide.
