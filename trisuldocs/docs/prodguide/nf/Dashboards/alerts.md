# Alerts

:::info navigation

:point_right: Select *Dashboards &rarr; Alerts* to view the Alerts Dashboard

:::

The **Alerts** dashboard gives you a consolidated view of alerts generated by Trisul. It helps you monitor which alerts were triggered, how frequently they occurred, their severity, and the systems or traffic involved.

Use this dashboard to review and investigate security and network events after they are detected.


[**Click here &rarr; to view the detailed Alerts doc**](/docs/guide/ug/ui/dashboards#alerts)
