# Long term traffic

:::info Navigation
:point_right: Go to **Tools &rarr; Long term traffic**
:::

**Long Term Traffic** lets you analyze how a particular network item behaves over a longer period, such as **weeks, months, or years**.

Select the Counter Group, meter, item, time frame, and chart type you want to analyze. You can also use **Handy Shortcuts** for common analyses.

For the complete search options, chart views, and result interpretation, see **[Long Term Traffic](/docs/guide/ug/tools/analyze_item)**.
