# NetFlow Sources

:::info Navigation
:point_right: Go to **NetFlow &rarr; NetFlow Sources**
:::

The NetFlow Sources dashboard shows where Trisul is receiving NetFlow data from and how much data each source is sending. It helps you monitor flow exporters (routers), interfaces, and the overall volume and rate of NetFlow data being processed.

Use this dashboard to check whether your NetFlow sources are actively sending data and to identify sources or interfaces carrying higher volumes of traffic.

For details on the dashboard and its charts, see [NetFlow Sources Dashboard](/docs/guide/ug/netflow/sources).
