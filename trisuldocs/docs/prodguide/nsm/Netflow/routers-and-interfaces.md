# Routers and Interfaces

:::info Navigation
:point_right: Go to **Netflow &rarr; Routers And Interfaces**
:::

The Routers and Interfaces tool gives you a device-level view of your NetFlow data. It lets you see which routers are active, how much traffic they carry, which interfaces are active, and how those interfaces are being used.

Select a router to view its interfaces, then drill down into interface traffic, hosts, applications, flows, utilization, and other network details.

For detailed information on the Router and Interface tables, filtering, visualizations, and available drill-down options, see [Routers and Interfaces](/docs/guide/ug/netflow/routers_and_interfaces)
