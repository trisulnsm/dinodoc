# Email Settings

:::info Navigation
:point_right: Go to **Reports &rarr; Email Settings**
:::

Email Settings lets you configure the email account Trisul uses to send scheduled reports and alerts.

Set up the SMTP server and sender address, test the configuration, and define the default recipient and email options for scheduled reports.

For detailed instructions on configuring the mail server, testing email delivery, and setting up default report recipients, see [Setup E-Mail](/docs/guide/ug/reports/emailsettings).
