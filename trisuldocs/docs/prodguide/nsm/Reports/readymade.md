# Readymade

:::info Navigation
:point_right: Go to **Reports &rarr; Readymade**
:::

Readymade Reports are built-in report templates for quickly generating common network traffic, security, endpoint, application, and NetFlow reports.

Choose a report category, provide the required information and time frame, and generate the report. Categories include Executive Reports, Endpoints and Applications, ISP Peering Analytics, Commonly Used, NetFlow, Direct, and Static IP reports.

For the complete list of reports, required inputs, and what each report provides, see [Readymade Reports](/docs/guide/ug/reports/readymade).
