# Real Time Stab Toppers

**Real Time Stab Toppers** shows the most active items in any counter group, updated every second. For example, you can show the most active applications by total traffic.

:::info Navigation
:point_right: Go to **Tools &rarr; Real Time Stab Toppers**
:::

Real Time Stab Toppers is one of Trisul's real time stabbers. Stabbers use the same port as the web interface (TCP 3000), so you don't need to open an extra firewall port.

For the other ways to open a stabber, the browser requirements and the other stabber types, see [Real Time Stabbers](/docs/guide/ug/cg/stabber) in the User Guide.
