# Show all

:::info Navigation
:point_right: Go to **Dashboards &rarr; Show all**
:::


Clicking on **Show All** lists the default dashboards and the user created dashboards all in one place. The **Show All** page can be used to 

- [**View all dashboards**](/docs/guide/ug/ui/create_dashboards#view-dashboards)
- Manage - [**Customize**](/docs/guide/ug/ui/create_dashboards#how-to-edit-a-dashboard), [**Clone/Delete/Export**](/docs/guide/ug/ui/create_dashboards#how-to-deletecloneexport-a-dashboard)
- [**Add new dashboard**](/docs/guide/ug/ui/create_dashboards#create-a-dashboard)
- [**Import a dashboard package**](/docs/guide/ug/ui/create_dashboards#how-to-import-a-dashboard).
