# MITRE ATT&CK

**MITRE ATT&CK** maps Trisul's network detections onto the MITRE ATT&CK framework, so instead of just seeing "an alert fired" you see which known adversary technique it lines up with. There's also a companion timeline view that lays these mapped detections out chronologically, so you can see how an intrusion actually unfolded.

[**Click here → to see which ATT&CK technique each alert maps to, browsable by tactic**](https://docs.trisul.org/docs/guide/ug/alerts/mitre)

[**Click here → to see mapped detections laid out in chronological order, so you can trace how an intrusion unfolded**](https://docs.trisul.org/docs/guide/ug/alerts/mitretimeline)
