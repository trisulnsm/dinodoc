# Network Behavioral Anomaly Detection (NBAD)

The **NBAD** section provides behavioral anomaly monitoring, protocol metrics, flow maps, and attack telemetry across your network.

## Available NBAD Modules

* [**Layer 7 Metrics**](layer7metrics) — Application-layer breakdown of traffic, SNIs, and TLS root CAs.
* [**HTTP Traffic**](httptraffic) — Detailed HTTP method, status code, and URL visibility.
* [**IPv4 / IPv6 Dashboard**](ipv4ipv6) — Side-by-side protocol transition tracking.
* [**Tunnels**](tunnels) — Encapsulated and tunneled protocol detection.
* [**P2P Analytics**](p2p) — Peer-to-peer traffic inspection.
* [**TCP Analyzer**](tcpanalyzer) — TCP health, retransmission, and latency diagnostics.
* [**Flow Map**](flowmap) — Live global geographic traffic mapping.
* [**MITRE ATT&CK**](mitre-attck) — Adversary technique mapping and alert timeline.
* [**DDoS Monitor**](ddos-monitor) — Volumetric spike and flood detection.
