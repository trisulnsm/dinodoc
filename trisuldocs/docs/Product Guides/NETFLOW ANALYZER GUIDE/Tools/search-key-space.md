# Search Key Space

:::info Navigation
:point_right: Go to **Tools &rarr; Search Key Space**
:::


Search Key Space lets you search Trisul's stored keys across Counter Groups. It is useful when you know a particular value, such as an IP address, application, or other key, and want to find where it appears in Trisul's data.

For detailed instructions on searching the key space and working with the results, see [Search Key Space](/docs/documentation/ug/tools/keyspace).
