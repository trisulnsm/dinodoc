# Flow Tagger

:::info Navigation
:point_right: Go to **Tools &rarr; Flow Tagger**
:::

Flow Taggers let you automatically add text labels to network flows when they match rules you define. You can use tags to identify flows based on criteria such as IP addresses, ports, protocols, countries, or other Counter Group activity.

Once flows are tagged, you can search for them, view the top flows associated with a tag, or aggregate them for further analysis. A single flow can also have multiple tags.

For detailed instructions on creating tagging rules, automatic tagging, tagger groups, and viewing tagged flows, see [Flow Taggers](/docs/documentation/ug/flow/tagger).
