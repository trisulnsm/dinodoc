Threshold Crossing Alerts (TCAs) let you automatically detect when a network metric crosses a threshold you define. You can set high and low limits and require the value to remain above or below those limits for a specified number of intervals before an alert is triggered or cleared.

Use TCAs to monitor things such as traffic volume, bandwidth, ports, IP addresses, or other Counter Group metrics and get notified when activity exceeds the level you consider significant.

For detailed instructions on creating, viewing, filtering, investigating, and scheduling Threshold Crossing Alerts, see [Threshold Crossing Alerts](/docs/documentation/ug/alerts/tca)
