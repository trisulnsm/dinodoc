# Real Time Traffic

:::info navigation

:point_right: Select *Dashboards &rarr; Real Time Traffic* to view the Real Time Traffic Dashboard

:::

**Real Time Traffic** provides a live view of **what is happening on the network right now**.

It shows the current traffic rate, traffic direction, and the internal hosts and applications contributing to that activity. Unlike dashboards used for analyzing traffic over longer periods, this dashboard is designed for **immediate visibility into current network activity**.

The dashboard uses Trisul's **Real Time Stabbers**, which allow the Trisul Probe to push events directly to the browser using **WebSockets**, providing a true real-time view rather than relying on periodic refreshes.

Use it when you want to quickly identify:

* Whether incoming or outgoing traffic is changing
* How much bandwidth is being used right now
* Which internal hosts are generating the most traffic
* Which applications are currently using the most bandwidth
