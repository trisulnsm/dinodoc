:::info Before you dive in
This page assumes a few core Trisul concepts. If any of these are new, the [Terminology guide](/docs/guide/learntrisul/terminology) has full definitions.

- **[Probe](/docs/guide/learntrisul/terminology#probe)** and **[Hub](/docs/guide/learntrisul/terminology#hub)**. Probes analyze traffic. Hubs store what Probes send them.
- **[Context](/docs/guide/learntrisul/terminology#context)**, a separate monitoring workspace inside Trisul, each with its own configuration.
- **[Home Network](/docs/guide/learntrisul/terminology#home-network)**, the network you have configured as your own. Everything else counts as external.
- **[Counter Group](/docs/guide/learntrisul/terminology#counter-group)**, a category of things Trisul measures, such as Hosts or Applications.
- **[Flow](/docs/guide/learntrisul/terminology#flow)**, a single network conversation between two endpoints.
:::
