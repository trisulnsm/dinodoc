# Trisul Apps

Trisul Apps extend the capabilities of Trisul Network Analytics with additional analytics, monitoring, visualization, and investigation features.

These apps provide focused functionality for specific network monitoring and operational requirements. Each app is designed to work with Trisul's existing analytics data and can be configured according to the required use case.

## Installing an App

Trisul Apps can be installed from the Trisul Web Admin interface.

To install an app:

:::info navigation
:point_right: Login as admin. Go to Web Admin &rarr; Manage &rarr; Apps
::: 

- Browse the available apps.
- Select the app you want to install.
- Follow the installation and configuration instructions provided for that app.

Some apps may require additional configuration or dependencies after installation. Refer to the individual app documentation for the required configuration steps.

## Available Apps

The following apps are currently documented in this section:

* [Stable Keys](./stablekeys) - Monitors the continuity of network keys and alerts when previously observed keys stop reporting.

## Using Trisul Apps

Each app has its own documentation covering:

* **Objective** - What the app is designed to achieve.
* **Workflow** - How the app works and how it can be used.
* **Configuration** - Available configuration options and parameters.
* **Output** - Alerts, metrics, or other information generated by the app.

Refer to the individual [**app documentation**](https://github.com/trisulnsm/apps/tree/apps7) for configuration and usage details.
