# Trisul Documentation

Welcome to the **Trisul Network Analytics** documentation. Trisul does real-time streaming traffic analysis, deep packet inspection and long-term network telemetry, so you can see network usage, bandwidth trends and security threats.

Whether you are setting up Trisul for the first time, managing probes and hubs, analyzing traffic patterns, or developing custom analytics with Lua and APIs, the documentation guides below will help you find what you need.

:::tip New to Trisul?
Start with the [Quickstart](/docs/guide/starthere/quickstart). It takes you from a blank server to your first login. To choose a product mode first, see [Product Modes](/docs/guide/starthere/what_is_trisul/productmodes).
:::
