# Trisul Documentation

Welcome to the **Trisul Network Analytics** documentation library. Trisul provides real-time streaming traffic analysis, deep packet inspection, and long-term network telemetry to give you complete visibility into network usage, bandwidth trends, and security threats.

Whether you are setting up Trisul for the first time, managing probes and hubs, analyzing traffic patterns, or developing custom analytics with Lua and APIs, the documentation guides below will help you find what you need.
